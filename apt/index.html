Ancien dépôt APT de CCS : archivé

Depuis CCS 0.20.1, CCS est publié dans le dépôt unique de mawena : apt.mawena.cloud. Cet ancien dépôt a été archivé le 23/11/2026 (son contenu reste dans le tag archive/ancien-depot-apt du dépôt GitHub).

Pour passer au dépôt unique :

curl -fsSL https://apt.mawena.cloud/installer.sh | sudo sh -s -- ccs
sudo rm -f /etc/apt/sources.list.d/ccs.sources
