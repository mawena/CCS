Claude Code partout : appareils, machines, comptes

CCS est un poste de travail complet autour de Claude Code : un chat graphique sur le bureau, sur le web, sur Android et sur iPhone ; vos PC, votre serveur et vos téléphones reliés par un réseau maillé, avec le calcul réparti entre eux ; et plusieurs comptes Claude Code qui travaillent comme un seul, avec bascule automatique avant chaque limite.

Sur Ubuntu 24.04 :

curl -fsSL https://apt.mawena.cloud/installer.sh | sudo sh -s -- ccs

Le script ajoute le dépôt APT signé de mawena (un seul dépôt pour tous ses paquets) puis installe le paquet ; les commandes qu'il lance sont détaillées plus bas, pour qui préfère les taper soi-même.

Ce que fait CCS

Changer de compte

Une commande, ccs switch, et les sessions déjà ouvertes suivent à leur prochaine requête.

Voir les limites

Session de 5 heures et semaine de chaque compte, prévision d'épuisement et conseil du meilleur compte à utiliser.

Basculer seul

Changement automatique avant d'atteindre une limite, plages de 5 heures enchaînées et décalées aux heures actives.

Comprendre l'usage

Analyse des journaux locaux de Claude Code par projet, modèle et heure ; notifications sur le bureau.

Une application GNOME

« CCS » en trois onglets (Accueil, Sessions, Analyse), thème clair ou sombre, une couleur par compte, conversations renommables, indicateur dans la barre du haut.

Un chat graphique

Les sessions Claude s'y travaillent dans un chat : modèle, effort, ultracode et droits en un clic, autorisations Autoriser / Toujours / Refuser, @ fichiers, / commandes, images.

Fichiers et feuille de route

L'arbre du projet avec ses marques git, les fichiers ouverts à côté du chat (aperçu Markdown, édition, diff des modifications de Claude) et la feuille de route aux cases cliquables.

Une page Git

Indexation par fichier, bloc ou ligne, commit, fetch, pull et push (le push forcé est gardé), git flow et graphe des commits, à côté du chat.

Le travail de Claude sous contrôle

Les fichiers que Claude a modifiés, annulables un par un ou jusqu'à avant un message ; « Faire une tâche » depuis la feuille de route ; Autoriser ou Refuser depuis la notification du téléphone.

Sur un serveur, depuis le téléphone

Le paquet ccs-serveur offre une version web pour le téléphone : chats, sessions, fichiers, feuille de route, Git, terminal, tâches de nuit, analyse et réglages.

Applications Android et iPhone

Les sessions de tous vos PC et de votre serveur dans la poche : chat, notifications, autorisations, vocal (dictée et lecture des réponses), mot de passe root validé d'un geste.

Toutes vos machines reliées

Un réseau maillé privé relie PC, serveur et téléphones comme sur un réseau local : fichiers de chaque appareil, son partagé, et ccs distant pour lancer un build ou une suite de tests sur une autre machine.

Un service discret

Un service systemd utilisateur veille en arrière-plan, pour tous les utilisateurs du poste.

Installer

Pour Ubuntu 24.04 et les distributions Debian équivalentes. Une fois le dépôt ajouté, sudo apt upgrade apporte les nouvelles versions.

  1. Ajouter la clé qui signe le dépôt :

    sudo curl -fsSLo /usr/share/keyrings/mawena-depot.gpg https://apt.mawena.cloud/mawena-depot.gpg

  2. Ajouter le dépôt :

    sudo curl -fsSLo /etc/apt/sources.list.d/mawena-depot.sources https://apt.mawena.cloud/mawena-depot.sources

  3. Installer :

    sudo apt update && sudo apt install mawena-depot ccs

  4. Vérifier l'installation :

    ccs doctor

Quatre paquets : ccs (commandes et ccs tui), ccs-bureau (application GTK), ccs-serveur (version web et accès à distance) et ccs-all qui les installe tous. Sur un serveur : sudo apt install --no-install-recommends ccs-serveur, puis sudo adduser <utilisateur> ccs.

Sans le dépôt : téléchargez le paquet .deb et sa somme de contrôle sur la page de la dernière version, puis sudo apt install ./ccs_*_all.deb. Il installe aussi mawena-depot, qui ajoute le dépôt : les mises à jour suivantes passent ensuite par sudo apt upgrade.
