CCS
Installer Dernière version Code source

Plusieurs comptes Claude Code, un seul poste

CCS garde vos comptes côte à côte et change de l'un à l'autre en une commande, sans se déconnecter ni se reconnecter. Il surveille la limite de 5 heures et la limite hebdomadaire de chacun, prévoit quand une session sera épuisée et bascule avant qu'elle ne le soit.

Sur Ubuntu 24.04 :

curl -fsSL https://mawena.github.io/CCS/installer.sh | sudo sh

Le script ajoute le dépôt APT signé puis installe le paquet ; les commandes qu'il lance sont détaillées plus bas, pour qui préfère les taper soi-même.

Ce que fait CCS

Changer de compte

Une commande, ccs switch, et les sessions déjà ouvertes suivent à leur prochaine requête.

Voir les limites

Session de 5 heures et semaine de chaque compte, prévision d'épuisement et conseil du meilleur compte à utiliser.

Basculer seul

Changement automatique avant d'atteindre une limite, plages de 5 heures enchaînées et décalées aux heures actives.

Comprendre l'usage

Analyse des journaux locaux de Claude Code par projet, modèle et heure ; notifications sur le bureau.

Une application GNOME

« CCS » : sessions reprises ou lancées dans des onglets de terminal intégré, conversations renommables, indicateur dans la barre du haut.

Un service discret

Un service systemd utilisateur veille en arrière-plan, pour tous les utilisateurs du poste.

Installer

Pour Ubuntu 24.04 et les distributions Debian équivalentes. Une fois le dépôt ajouté, sudo apt upgrade apporte les nouvelles versions.

  1. Ajouter la clé qui signe le dépôt :

    sudo curl -fsSLo /usr/share/keyrings/ccs.gpg https://mawena.github.io/CCS/apt/ccs.gpg

  2. Ajouter le dépôt :

    sudo curl -fsSLo /etc/apt/sources.list.d/ccs.sources https://mawena.github.io/CCS/apt/ccs.sources

  3. Installer :

    sudo apt update && sudo apt install ccs

  4. Vérifier l'installation :

    ccs doctor

Sans le dépôt : téléchargez le paquet .deb et sa somme de contrôle sur la page de la dernière version, puis sudo apt install ./ccs_*_all.deb. Le paquet ajoute lui-même le dépôt : les mises à jour suivantes passent ensuite par sudo apt upgrade.
